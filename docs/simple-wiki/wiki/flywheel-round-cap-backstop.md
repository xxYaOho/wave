# 飞轮轮次封顶与兜底收场

SPEC 修正轮存在「纸面完备性长尾」：每轮 fresh 审查修好旧账又在相邻处揭出新表述缺口，FATAL 计数低位震荡不收敛（实测 C2 十轮 6→5→7→2→5→3→2→4→4→3；P1b 八轮 5→5→6→3→1→2→1→2）。[C2 审查台账](../raw/2026-11-13-c2-review-ledgers.md) [P1b 审查台账](../raw/2026-11-13-p1b-review-ledger.md)

## 治法

1. **轮次封顶**：生命周期修正轮 ≤4，用尽即硬停升级。
2. **显式早停判据**（成文，不靠自觉）：同实质 FATAL 两轮未缩小；或连续两轮「引入新 FATAL 且旧账未清」。
3. **兜底收场**：最终轮授权时预承诺失败后果——末轮 FAIL 即冻结 SPEC 现状，未决发现转为**闸门实证清单**（实现要求，交付闸门实跑验收），直接进施工。

## 实证

P1b FULL-8 后兜底收场：4 项纸面缺口（版本源/探针/占位符/优先级）转为 gate 清单，实现时一次性做对，闸门实跑全绿——验证负担从纸面挪到可执行证据后，长尾即刻终止。
